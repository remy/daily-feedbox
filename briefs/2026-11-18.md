# Feedbox brief — Wednesday 18 November 2026

A Swiss non-profit is **switching off DNS for a whole country**. Quad9 stops answering French queries on 24 November. A Paris court fined it for refusing to block pirate sports domains, and roughly twenty more cases are queued. Cloudflare calls the exit [a canary in the coal mine][cf-quad9]. Quad9's own CTO asked for a long-form case against the policy. [Tech Stackups wrote one][quad9], tracing the law to a single clause in the French sports code.

The [2026 State of HTML results][soh] are out, with 2,091 respondents. Kilian Valkhof wrote the conclusion and [his own read of it][valkhof]. Both land on the same shift: **declarative wins**. Invoker commands and customisable select replace lines of imperative code. Browser pain has also changed shape, from engines doing things differently to engines simply lagging. Accessibility came through as a top concern. Separately, Patrick Brosset built [a tool that credits each feature's first engine][brosset].

Personal publishing threw up a different question: what survives. Dave Winer released BonBon, a Markdown browser ([his post][winer] is outside these feeds). Frank McPherson ran the Linux build and [found the honest limit][mcpherson]. There is barely any Markdown to read, and links hand off badly in both directions. The same bet has a longer record. blog.lmorchard.com has run [across five engines in 24 years][orchard24], and just [had its generator rebuilt][orchard2]. **The Markdown files in git outlasted every platform.**

Three developers asked the same question on Wednesday and gave three answers. Baldur Bjarnason argues the [real risk is not replacement but reclassification][baldur]. A Ruby team doing front-end work with agents is **a specialist replaced by a non-specialist**. Pay follows. Go Make Things [sizes up the exits][gmt] and lands on unions. Nelson Minar [gave the craft up happily][somebits], then notes he is retired and not doing high-stakes work. This runs on from Thursday's human-made-line thread, turned toward wages.

## Talking points

1. **A chart can be a table that someone styled.** Keith Cirkel builds columns, heatmaps, donuts and line charts with no JavaScript at all. Each starts from the element that already means the right thing. With the stylesheet off, each still reads as a table or a list. [Charts in HTML and CSS][cirkel]

2. **Two critical NGINX holes went public together, and one is eleven years old.** Both need HTTP/2 enabled, both score 9.2, and five teams found them separately. Wiz ran code on a server doing nothing but static files. [The disclosure][wiz] drew [an immediate memory-safety roast][xeiaso].

3. **Gez Lemon's ARIA conformance checker is now an extension.** It implements the author rules from ARIA in HTML, so it tells you which ARIA you were not allowed to write. The bookmarklet fails on sites with strict cross-origin rules; Steve Faulkner [wrapped it to get around that][faulkner].

4. **The comment box did not lose an argument, it lost to spam.** Lireo has had no human comment since July, against roughly 300 spam ones a month on fewer than ten posts. After 17 years, [comments are off][lireo]. Tuesday's brief ran the argument over reply mechanisms. This is the plainer reason they are needed.
