# Feedbox brief — Tuesday 27 October 2026

[Netmeister][sustain] says the run of security bugs cannot go on, picking up Friday's php2shell thread. The point is about defenders, not patches. **Having the fix was never the hold-up.** Finding every bundled copy is. The post names CA trust stores no SBOM lists, and a kernel escape still rated medium twelve days on. **AI-written bug reports make it worse.** Nobody reads seven thousand words a fire.

[Herman hid the upvote counts][dilemma] on Bear Blog's feed. The button stays; only the numbers went. Big counts pull in more votes, he argues. A lonely "1" next to someone else's "214" just stings. So he measured. **Votes, voters and click-throughs all held steady**, but the votes spread over **more posts**. [Sal][salup], no fan of upvotes, cheers him on.

Alex McLean put out [Strudel's post-AI policy][strudel], hardening the refusal Sunday's brief tracked. It starts from GCC's policy. LLM output is turned away in code, commit messages and issue threads. Private use stays private. **Anthropic came to the project**, offering a donation in return for working with its tools, and five-figure deals for artists. [Jovi De Croock][becoming] is the other pole: agents freed him from typing, and **he likes what the job is becoming**.

Two posts poked at what CSS already does. [Ahmad Alfy][select] shows what `appearance: base-select` changes. An option can now hold a font preview, the local time, a job title or a warning. **The deciding fact goes inside the option.** It falls back to a plain select, so **nothing breaks**. [Vale][tables] digs up the older oddity, `display: table`, and the layouts people once built with it.

## Talking points

1. **An allowlist is not a wall.** [Henrique Dias][filebrowser] traces File Browser's command bugs to things he took for granted at sixteen or seventeen. `find -exec` walks straight past the list, and `ls; id` passed the check.

2. **Whether AI works is the wrong question.** [Henry][works] says both answers land in one place: it takes the jobs, or it is the cover for taking them. Wages fall either way.

3. **Undo is design work, not a flag.** [Karl Koch][undo] shows a tidy-up turning "ask Sam whether Friday is realistic" into a firm promise. Keep the first draft next to the new one.

4. **Someone built a working 8086 in CSS.** [x86CSS][x86] runs compiled C with no JavaScript, in Chromium only. The author says plainly that no model helped.
