# Feedbox brief — Tuesday 20 October 2026

Nolan Lawson asks whether [web components have a future][lawson] if agents write the front end. His answer: **the original case has weakened**. They assumed hand-typed HTML and scarce code, so reuse paid. He still backs a self-contained widget like his emoji picker. He says server rendering, shared styles and access for all users are still unsolved. Work on the platform goes on: [Seokho's post][highlight] covers `::highlight(*)`, due in Chrome 158, which sets one shared default for all named highlights.

The IndieWeb row over Aaron Parecki's Claude-written code ran on from Saturday's brief. [vhbelvadi sides with Brennan Brown's caution][vhb]. The case is **precedent, not code quality**: if Parecki and Torvalds say understanding the output is enough, less careful people will hear a green light. He calls the rival webmention code plurality by technicality. Separately, [Gardiner Bryant likens AI coding to Visual Basic][gb]: prototypes that quietly become the core of a business.

Meta keeps drawing scrutiny. After Saturday's brief on its scraping language, [Pixel Envy relays Nieman Lab][pxl]: the revised terms drop "train", but legal experts say **broad scraping is still allowed**. [Fingerprint says Muse arrives with no verifiable identity][fp]. And [redact.dev found hidden text in WhatsApp's help pages][redact], telling its support AI not to point users to a regulator.

Three failures show how thin the plumbing is. [A 10MB atproto record][jola] made nine relays ask for the same data again and again from one personal server, and **the cursor never moved**. A [Google Cloud power event][bbc] in europe-west2 hit UK banking apps. And [kaba.cx traced 333 Tor exit nodes][tor], about a tenth of all exits, to an attack on SSH logins. Tor flagged them within two days.

## Talking points

1. **Standards now have to win on results.** If nobody types the markup, ease of use stops being the pitch. Server rendering and access for all users are what is left to fix, as [Lawson argues][lawson].
2. **Hidden prompts are the new fine print.** WhatsApp's help pages held text only an AI could read, with orders the privacy policy contradicts. [redact.dev checked 545 pages][redact] and found 80 with hidden blocks.
3. **AI is reviving abandoned hardware.** People are reflashing bricked mirrors, baby monitors and smart TVs with AI-written software. [404 Media reports][reverse] it spread over the weekend, giving back features that makers took away.
4. **A key warning caught a Tor-wide attack.** [kaba.cx noticed][tor] because SSH warned of a changed host key. Clicking through would have given away a password.
