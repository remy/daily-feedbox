# Feedbox brief — Saturday 21 November 2026

The Riemann thread ran on from Friday's brief, and now holds two rival claims. [Terence Tao's blog][tao] lists the results in decreasing order of how digested they are. Levent Alpöge's Generalized Riemann Hypothesis proof comes last. It is a Lean-only proof from an internal AI model, and verification is being worked out in a Zulip thread. [math216][m216] separately announced Alessandro Masullo's GRH proof. **Brian Conrad has checked that one for months**, and it uses **no AI at all**.

GnuPG shipped [GPGME 2.3.1][gpgme] on Friday. It fixes a critical bug in every prior version. A crafted long user id in an OpenPGP key triggers a double free. **Remote code execution cannot be ruled out**, and most mail clients, many XMPP clients, Samba and Flatpak all use the library. An unrelated GitLab bug pulled the disclosure five days early. [Seth Larson][larson] makes the structural point: before this change, **only repository admins could publish an advisory**.

[Matt Mullenweg launched Spacefast][spacefast] on Saturday, a host an agent can publish to directly. He quotes its founder, Batuhan İçöz, saying code is **removing the need for a CMS on many sites**. [Caleb Hailey][hailey] takes another line from the same manifesto, that HTML is the new PowerPoint. On the same day [gordonmclean.co.uk][gm] wants out of WordPress after more than 20 years, counting **almost 9,000 generated lines of code for one post**.

Two posts aimed coding agents at unlikely hardware. [ClawDOS][claw] is a coding agent for DOS. It runs on an IBM PC XT at 4.77 MHz, and its 176 KB harness speaks the Claude API itself. **Claude wrote all of the repo but one note.** [ankitg.me][fpga] got an LLM running on an FPGA instead, reaching 213 tokens per second. That one took **$10,000 in tokens** and roughly 3M lines of experiment history.

## Talking points

1. **The argument the maths thread is having was published in 2000.** Ted Chiang's [Catching Crumbs from the Table][chiang] imagines human scientists reduced to interpreting results they cannot originate. Tao's word for the work ahead is digestion.

2. **Anthropic's safety-versus-shareholders question now has a price attached.** Its shares fell 9% on Friday to $88.30, close to the $83 offer price. The [Nasdaq erased all its 2026 gains][nasdaq] the same day.

3. **A feed with no like button is the interesting part.** [timomeh.de][timo] sketches social media as a swipeable timeline of ordinary websites. Replies live on your own site, and the protocol passes identity, so commenting needs no login.

4. **The caveat is the honest bit.** [pour][pour] ships 55-plus accessibility simulations. It says each stands in for a problem a page has, not for what any person experiences. Findings marked for review still need a person.
