# Feedbox brief — Sunday 8 November 2026

A one-contributor repository got a code reviewer on Saturday. [A Read-Only AI Reviewer for Forgejo Pull Requests][hofstede] describes a bot that comments on pull requests and does nothing else. It never pushes, merges or approves. The first version produced findings that read well and were **plainly wrong**, because the model guessed at code outside the diff. A second pass now reads the repository first. It caught a real bug: **edits typed during a save were silently discarded**.

Two posts drew firm lines round the same tools. [Why I will not be using LLMs in my coding][polso] ends a year of soul-searching. Its grounds: an LLM is **a service, not a tool**. [My Opinion on AI Vibe Coded Camera Firmware][fuji] answers two readers who disagreed. A bricked camera is **a matter of when, not if**. [Vibe anything, fast][janlukas] sits at the other pole. It ships a Go tool for a statement of operating costs.

Three posts describe one drift: sensing moved into kit already in place. [Ads in Popular Apps Give Police a Powerful Tool to Spy on Users][bloomberg] reports Penlink's Webloc. It gathers location data from ads in weather, gaming and email apps. It holds **twelve months of movement** per phone. In the United States it needs **no warrant**. Peers want [abuse-image detection on every device sold in Britain][observer], on by default. [Turning Every Radio into a Radar][tiami] makes 4G a passive radar.

The personal web spent Sunday on maintenance. [S1524][samwilson] answers its own Saturday complaint about hosting: with tested backups and immutable archiving, **it still works**. [Migrating Lowkey Party back to BSSG][lowkey] goes back to a static generator to be rid of PHP, and gives up its comments to do it. [Addition of an Atom feed][matto] puts Atom beside RSS. [Self-Hosting Excalidraw][zylstra] is **not autonomous at all**, because collaboration stays on excalidraw.com.

## Talking points

1. **A used accessibility phone was e-waste, so it got a new operating system.** [Porting Android 16 to my blind mother's keypad phone][z1x] starts with a Kapsys SmartVision3, bought for 400 dollars. It shipped Android 11, bloatware, and a "booster" app to fix the lag.

2. **LLMs are worst at building things that use LLMs.** [LLMs are terrible at designing AI systems][goedecke] watched agents reach for symbolic solvers instead of one more model call. One agent circled a dead end for weeks. Asked why, it named the problem as unsolvable for 130 years.

3. **Agent memory has four formats and no agreement.** [Agent memory needs its OpenTelemetry moment][lorekit] counts `AGENTS.md`, Cursor rules, a memories directory and an MCP knowledge graph. None can read the others. The author builds one of these tools and says so.

4. **Support is the job, not the code.** [Taking a week off open-source support][madeline] records fourteen years of answering it daily, and one week off. Checking the channels had become the first act of the morning.
