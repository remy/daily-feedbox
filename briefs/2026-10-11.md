# Feedbox brief — Sunday 11 October 2026

Saturday's brief ran Anthropic pulling live internet from its evaluations. The containment argument has now reached Microsoft. On Saturday Satya Nadella argued we should **assume every model is compromised**. He wants an emergency brake so an authorised person can [stop one mid-task][nadella]. Pxlnv, on Sunday, left the substance alone. He [objected to the vocabulary][pxlnv]. The essay says "super intelligence" four times and never uses the word "artificial".

Three Sunday posts ask what the human is for once agents write the code. Piotr Sarnacki read DHH's AI rewrites of Campfire and found that [**an underspecified prompt turns design choices into coin flips**][sarnacki]. The Rust version quietly dropped the CSRF token and Redis. Jovi De Croock goes the other way and wants [**humans to approve intent while machines prove conformance**][decroock], so no one reads the diff. Matt Casmith [sits between][casmith]: ten minutes of review caught Copilot misreading a metric.

Two small traps: things that run where you did not look. Ned Batchelder wrote a zsh function that [lists active git hooks][ned] whenever you enter a repository. It follows a [near miss][wiles] from a blog outside the feed, where a shared folder arrived with live hooks. A reader [ported it to fish][offby1]. Separately, an agent sandbox's warning led disconnect3d to show that [a quoted tilde in PATH stays literal][tilde]. It adds a relative directory instead of your home.

The small-web end of the feeds. Lars-Christian found his hand-coded home page had [swollen to 123 kB][lars], mostly through images. A profile photo went from 60 kB to 4 kB as a JPG. The AVIF version kept the dithered look at 16 kB. The page can now be as small as 25 kB on older screens. His own footnote admits that asking an LLM for help cost more than the site will ever save.

## Talking points

1. **Reading the code is still the job.** In Sarnacki's account, the Rust rewrite [ran blocking database calls inside async tasks][sarnacki], and a load test showed it delivering only one per cent of notifications. A throughput benchmark would never have caught that.

2. **An emergency brake is the easy part to endorse.** Nadella's version asks for [containment and tamper-proof evidence][nadella]. That echoes others in the field. The hard question is who holds the switch, and that is the one the essay leaves open.

3. **Police dislike being tracked, too.** Anthony Sistilli built a licence-plate camera that logs only police cars, and officers [came to his house][flock] on 20 September. Flock says its own network now exceeds 120,000 cameras. This continues the Flock thread from Tuesday's brief.

4. **Pay a few strangers to follow your README.** Terence Eden spent about €150 on €25 hour-long sessions and [found a wrong demo link][readme]. The README never said what the software did. Real people, he argues, beat a simulated user.
