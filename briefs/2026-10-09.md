# Feedbox brief — Friday 9 October 2026

Thursday's brief ran the case for a plainer, agent-facing web. The counter-argument landed on Friday from a different direction. [Aaron Gustafson][gustafson] quotes Apple's WebKit team opposing the WebMCP proposal. When a site's actions defeat an agent, they argue, that is **a gap in the page's own semantics**. Close it in HTML and ARIA, where people, assistive technology and agents all gain. Gustafson's own worry is sharper. A parallel layer lets developers **polish the agent view and neglect the human one**.

Thursday's brief also ran the argument that "supported" and "accessible" are different claims. [Igalia][igalia] has now built a test layer that could settle it. Its new aamtest type checks platform accessibility APIs directly, and **190 tests cover four specs**. They have already caught Firefox emitting one event where the spec wants two, and **a wrong statement in the HTML-AAM spec**. [Sarah Higley][higley], separately, wants an interactive list role for the card grids everyone already ships.

Two Friday posts put the coding-agent problem in different places. [mtlynch.io][mtlynch] argues the models improved while **the agents stayed bad**. Its evidence is mundane: ten independent subtasks run one at a time. The agent never hands cheap work to a cheaper model. It also searches the web to learn its own features. [Programming Isn't Special][glyph] looks past tooling entirely. Programmers accepted AI, it argues, because they decided **programming is not art**.

The feeds also carried the usual quiet making. A [memoir post][simcity] traces a hex editor and **a SimCity 2000 save file** into a first lesson in bytes. [OutRun GB][outrun] puts the whole arcade original on a Game Boy Color, tracks and music included. Wes Bos rooted a **$50 Amazon photo frame** into a [family dashboard][wesbos], stripping the stock software for a modern WebView.

## Talking points

1. **Deno's runtime gets a year, then stops.** The team is [joining Cloudflare][deno]. Deno Deploy closes in six months and JSR carries on. The [companion post][cloudflare] spends its length arguing Workers was never a lock-in trap. Both things are true, and they still read oddly together.

2. **Blame the downvotes, not the model.** [honeypot.net][honeypot] points at the Stack Overflow newest-questions page, where new askers collect negative scores. That traffic graph has been falling since 2016. Handy the next time someone credits AI with the whole decline.

3. **Chrome 154 can size an iframe to its content.** One CSS property on the parent replaces the postMessage dance, as [alfy.blog][alfy] walks through. The embedded page still has to opt in with a meta tag. The cooperation problem did not vanish. It moved into the browser.

4. **Bootstrap 6 alpha drops its fallbacks.** The [new floor][bootstrap] is Chrome 130, Firefox 132 and Safari 18, because v6 builds on `light-dark()`, `:has()`, container queries and `oklch()`. No prefixes, no polyfills below that. v5 stays supported, for now.
